# Regulamento de Benefícios Estudantis

Documento fictício criado para testes. Regula os benefícios que a universidade concede aos estudantes.

## Definições

Bolsa Alimentação Estudantil (BAE): benefício que concede um cartão com saldo mensal para comprar alimentos.

Serviço de Bem-Estar Estudantil (SBE): unidade que administra os benefícios, doravante o Serviço.

## Valores

| Benefício | Valor mensal |
|---|---|
| Bolsa Alimentação Estudantil | 32.000 pesos |
| Bolsa Transporte | 18.000 pesos |
| Auxílio Emergencial | 150.000 pesos uma única vez |

## Candidatura

O SBE recebe as candidaturas em março de cada ano. O Auxílio Emergencial pode ser solicitado em qualquer momento do ano.

## Requisitos

Para manter a BAE é preciso ser aprovado em pelo menos 60 % dos créditos inscritos.

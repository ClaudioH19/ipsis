# Banco coloquial

30 preguntas por idioma (es/en/pt) escritas como habla la gente («cuanta plata
sale el almuerzo», «how long till my screen locks», «quanto aguenta a lampada»)
sobre los hechos del [banco de validación](../banco_validacion/), con sus
mismos documentos y distractores.

- 24 paráfrasis informales con vocabulario cotidiano;
- 4 trampas del mismo tema junto a su par («la once», «the pool», «meus pais»);
- 2 fuera de dominio.

**Para qué sirve:** banco retenido para las equivalencias coloquiales de los
paquetes. Se escribió el 2026-10-10 antes de curarlas y no se miró para
elegirlas: se mide una vez antes y otra después, solo en agregados. Si una
lista se amplía mirando sus fallos, deja de ser retenido.

Fuentes: `<idioma>/casos.yaml`. Derivados: `python tests/datos/banco_coloquial/construir.py`.

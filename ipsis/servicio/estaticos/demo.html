Bienvenido

Esta página no tiene relación real con ningún negocio: existe solo para comprobar que el widget de chat (/widget.js) se integra con una sola línea y que su CSS no se filtra hacia esta página, ni al revés (el widget vive dentro de un Shadow DOM).

Botón de ejemplo del sitio anfitrión

Prueba los cuatro estados

Después de cargar e indexar tus documentos, prueba preguntas como estas para comprobar los cuatro estados:

  • ok: una pregunta respondida literalmente por tus documentos.
  • relacionado: una pregunta cercana al contenido pero sin respuesta directa.
  • sin_respuesta: "¿Cuál es la capital de Mongolia?"
  • conversacional: "hola"

El botón flotante de chat está en la esquina inferior de la pantalla. Si esta página se sirve desde el propio servicio (/widget/demo.html), data-api se deja vacío a propósito: el widget usa window.location.origin como base por defecto.
